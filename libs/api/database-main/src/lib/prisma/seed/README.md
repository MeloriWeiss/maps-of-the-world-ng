# Development seed

Команда `yarn db:main:seed` полностью очищает локальную main-базу и создаёт
детерминированный набор данных для ручной проверки приложения.

Перед запуском должны быть доступны PostgreSQL и MinIO:

```bash
yarn start:api-deps:docker
yarn db:main:deploy
yarn db:main:seed
```

Тестовые аккаунты используют пароль `Admin123`:

- `admin@example.com` — суперадминистратор (`SUPER_ADMIN`) и основной владелец
  контента;
- `user@example.com` — обычный пользователь;
- остальные логины перечислены в `users.ts`.

Эти данные предназначены только для локальной разработки. Не запускайте seed и
не используйте тестовый пароль в production. При `NODE_ENV=production` seed
завершится ошибкой до очистки базы.

Основные сценарии:

- `/forum` — 55 тем, по 20 на странице, поиск и четыре категории;
- `/texture-packs/10000000-0000-4000-8000-000000000001` — 62 текстуры,
  поэтому кнопка загрузки следующей страницы активна;
- каталог карт содержит 30 опубликованных карт;
- профили содержат опубликованный контент и черновики;
- комментарии форума включают три уровня вложенности;
- в базе есть лайки, активные и просроченная сессии, nullable-поля и пустой
  текстур-пак.

Placeholder-изображения загружаются в настроенное S3-совместимое хранилище.
Если хранилище недоступно, наполнение PostgreSQL завершается успешно с
предупреждением, но изображения по seed-ключам не будут открываться.
